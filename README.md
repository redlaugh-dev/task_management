# Менеджер задач
Небольшой проект на витрину. 
## Основной функционал
### Работа с задачами:
- Каждая задача содержит основные поля: название, описание, дата создания, статус выполнения
- Задача связана с автором (кто поставил) и исполнителем (кому назначена)
- Возможности:
  - Добавление/редактирование/удаление задач (в рамках прав)
  - Изменение статуса задачи
  - Фильтрация задач по статусу, дате, исполнителю (для Manager и Admin)
### Админ-панель:
- Управление пользователями: просмотр, создание, редактирование, удаление
- Изменение ролей пользователей
- Просмотр всех задач в системе
- Поиск пользователей и задач

### Пользовательские роли и доступ
- User (Сотрудник)
  - Может просматривать только свои задачи
  - Может изменять статус своих задач (например, "выполнено")
- Manager (Руководитель)
  - Имеет доступ к списку задач, которые он назначил другим пользователям
  - Может создавать задачи и назначать их другим пользователям (с ролью User)
  - Может изменять, удалять и отслеживать назначенные им задачи
  - Может просматривать статус выполнения задач
- Admin (Администратор)
  - Имеет доступ ко всем пользователям и задачам (может редактировать)
  - Может создавать, редактировать и удалять любых пользователей
  - Может изменять роли пользователей
  - Может управлять всеми задачами в системе
