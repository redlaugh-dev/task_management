Небольшой проект на витрину. 
Основной функционал
Работа с задачами:
- Каждая задача должна содержат основные поля: название, описание, дата создания, статус выполнения
- Задача связана с автором (кто поставил) и исполнителем (кому назначена)
- Возможности:
  - Добавление/редактирование/удаление задач (в рамках прав)
  - Изменение статуса задачи
  - Фильтрация задач по статусу, дате, исполнителю (для Manager и Admin)
Админ-панель:
- Управление пользователями: просмотр, создание, редактирование, удаление
- Изменение ролей пользователей
- Просмотр всех задач в системе
- Поиск пользователей и задач
